# Sales-Dashboard

# Project Overview
This project features a dynamic and interactive Sales & Target Performance Dashboard built in Microsoft Excel. It is designed to provide a comprehensive view of organizational sales health, tracking performance against set targets across various dimensions such as time, geography, personnel, and product categories.
The dashboard enables stakeholders to quickly identify top-performing regions and managers, monitor monthly trends, and understand product category contributions to overall revenue.

# Key Metrics (KPIs)
The dashboard tracks five primary Key Performance Indicators to provide an immediate snapshot of business success:
Total Sales: 7,11,78,664
Total Target: 4,16,93,329
Achievement %: 170.72% (indicating performance significantly exceeded targets)
Total Orders: 500
Units Sold: 2,716

# Visual Insights
Monthly Sales Trend: A dual-line chart comparing Total Sales against Total Target month-over-month, highlighting seasonal peaks and performance gaps
Sales by Region: A bar chart breaking down revenue across four key territories: East, North, South, and West
Sales by Manager: A horizontal bar chart ranking the performance of eight managers (Manager_1 through Manager_8) to identify top talent
Category Contribution: A donut chart showing the revenue split between Electronics (29%), Accessories (25%), Clothing (24%), and Furniture (22%)
Top 10 Products by Sales: A column chart identifying high-volume products such as Headphones, Laptops, Shirts, and Phones

# Interactive Features
To allow for granular data exploration, the dashboard includes interactive Slicers that filter all visualisations simultaneously:
Region Slicer: Filter data by East, North, South, or West
Product Category Slicer: Drill down into Accessories, Clothing, Electronics, or Furniture
Month Slicer: Select specific months to view periodic performance

# Technologies Used
Microsoft Excel: Core platform for data processing and visualization
Pivot Tables & Pivot Charts: Used for dynamic data aggregation and reporting
Slicers: Implemented for an interactive user experience
Conditional Formatting & Advanced Charting: Used for professional dashboard aesthetics
